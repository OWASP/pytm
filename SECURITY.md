# Reporting a Vulnerability

Please do **not** report (suspected) security vulnerabilities in a public issue.
Use GitHub's private vulnerability reporting instead: open the
[Security tab](https://github.com/OWASP/pytm/security) of the repository and
choose **Report a vulnerability**.

You will receive a response from us within 48 hours. If the issue is confirmed,
we will release a patch as soon as possible depending on complexity but
historically within a few days.

Note that `threats.json` conditions are evaluated as code (see the warning in the
README), so only load threat files you trust.
